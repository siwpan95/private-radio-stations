### 关键逆向事实（供再失效时续推）

**乐嗨/秀色（XSH5Utils 签名体系，已完整复刻）**
- 乐嗨根 `https://service.lehaitv.com/v2`；游客 `GET /v2/user/registervisitor` → `data.sessionid`(=accessToken，服务端已 URL 编码，签名时双重编码/请求时单次编码)、`data.uid`(=tku)；拉流 `GET /v2/room/{rid}/media/advanceInfoRoom`。
- 秀色根 `https://service.showself.com/v2`；游客 `GET /v2/custuser/visitor`（sessionid 为 32 位 hex 无编码问题）；拉流 `GET /v2/rooms/{rid}/media/latest`。
- 签名：`_ajaxData1 = md5( join(sorted([f"{k}={encodeURIComponent(v)}" for k,v in params if v!='']), '&') + SALT )`；乐嗨盐 `1eha12h5`、秀色盐 `sh0wselfh5`（= 4 常量各 substring(4) 拼接）；`_st1`=毫秒时间戳。十步变换链 pt() 只有 ac 一步有效（整体就是排序+MD5+盐），DES 仅用于业务加密接口（data1 字段，密钥 `p1ayback`），拉流不涉及。
- 流字段：`data.media_url_web` → 回退 `medial_url_app_for_h264`/`media_url_app`。

**六间房（v6stream 新流体系）**
- 房间页内联 `flvtitle: v{uid}-{sid}`；节点查询 `https://oir.6rooms.com/live/?s={uid}`（rio 同源）→ XML `<hip>`（当前 wlive.6rooms.com）。
- 现行拉流：`https://{hip}/liverecord/{flvtitle}.flv`（免签名直出）/ `.../playlist.m3u8`；播放器真实请求另有带参形态 `{hip}/httpflv/{flvtitle}.flv?os=9&page=room&ruid={uid}`（302→CDN），两路均有效。
- 主包 bl.v1.8.35.js 与 dll1/dll2 是壳/厂商包，无端点；真相源在移动端 v2：entry → chunk 9812 → embedliveplayer（chunk 7799）的 `makeStreamingUrl`。

**YY（Thunder 流系统）**
- `POST https://stream-manager.yy.com/v3/channel/streams?uid=0&cid={rid}&sid={rid}&appid=0&sequence={ms}&encode=json`，body={head, client_attribute, avp_parameter(gear=4 最高档, stream_format=1=m3u8/0=flv)}，响应 `avp_info_res.stream_line_addr.{appid}_xv_...cdn_info.url`；未开播/不存在时该字典为空。
- 兜底：`GET https://interface.yy.com/hls/new/get/{rid}/{rid}/1200?source=wapyy&callback=`（JSONP）→ 开播直返 `hls` 字段。旧第二跳 `hls/get/stream/15013/...` 已废（`{"hls":"not found"}`）。
- 直链含 t/tk 时效签名（分钟级），必须即时使用。

**央视频（双路线）**
- 主路线（免登录）：`https://vdnx.live.cntv.cn/api/v3/vdn/live?channel={cctv1...}&vn=1&pdrm=1&uid=&hbss={ms}`，头 `auth-key = "{hbss}-{rn}-{md5(channel+hbss+rn+secret)}"`（secret=PC 端公开静态串 `a4220a71b31746908fa3e7fdd7a6852a`）→ `manifest.hls_cdrm`（CDN 轮换，最高 720p）。
- 频道映射：12 位频道 id → `m.yangshipin.cn/tv?vid&pid` meta-refresh 解析真实 pid（CCTV-1=600001859）→ `h5access.yangshipin.cn/web/h5_live_poll` 取标题（CCTV1）→ 央视网频道名（cctv1）；特例 cctv5+→cctv5plus、cctv9→cctvjilu、cctv14→cctvchild。
- 备路线 txvlive：encryptVer 仍 8.1，appVer 升到 1.44.1（H5 播放器 ysplayer.modern）/3.0.47（App）；ckey 两段式——首请求 cKey=Ut(vid,本地时间,...)，iretcode==32/有 svrtick/curTime 时用服务端时间重算重试；Ut 本体控制流平坦化混淆（js 内执行）。央视频道走 vdnx 已足够，ckey 路线保留给免费/非央视频道。

**抖音**
- `live.douyin.com/{web_rid}` 房间页 SSR 内嵌 `roomStore.roomInfo`（status=2 直播中 + stream_url / flv_pull_url / hls_pull_url_map），**免签名免 cookie**；`\u0026` 等转义必须还原否则 403；流地址带 expire/sign 时效签名（分钟级）。
- 输入契约变化：只认 web_rid 短号或分享链接；19 位 room_id（app_id=1128 时代）已死。
- 需要签名的 `webcast/room/web/enter/`（a_bogus/msToken/ttwid）仅作备选，未采用。

### 关键逆向事实（供再失效时续推）

**斗鱼（旧式 flv 直链已全线死亡；token 时效分级）**
- 旧模块只取流 key、拼 `http://vplay1a.douyucdn.cn/live/{key}.flv?uuid=`——**uuid 恒为空**。实测：vplay1a 连接失败、tx2play1 404、akm-tct/ws-tct 403、hls3-akm SSL 错误。
- **时效分级（实测，勿再猜）**：① `hlsH5Preview`（`POST playweb.douyucdn.cn/lapi/live/hlsH5Preview/{rid}`，头 rid/time/auth=md5(rid+t13)，body {rid,did}）返回 `rtmp_url`+`rtmp_live` 拼接的 m3u8——**txTime 仅约 1 分钟**（实测 71s 后 403），只够立刻播放；② m 站 `ratestream`（m.douyu.com 页面内嵌 `ub98484234` 签名函数，execjs 执行，params 附 `ver=219032101&rate=-1`）返回 `data.url` 原画直链（`_2000.m3u8`）——**txTime 约 2 小时（实测）**，是现行最长效直链，作主路线；③ 内层变体 URL（livehwc4.com，带 user_session_id/edge_slice）与主列表同 txTime（约 1min）。
- `data.multirates` 对测试房为空；PC 页签名正则（www.douyu.com 的 `vdwdae325w_64we` 块）已随官网换代抓不到，`get_pc_js()` 不可再当主路线；m 页签名仍有效。
- **遗留（可选增强）**：ratestream 直链 2 小时后同样过期，长时间转播需 station 层「重解析再重试」机制（抖音/YY 同类分钟级直链也受益），待拍板。
